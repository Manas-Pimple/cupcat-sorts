# CatCup Sorts 

An interactive educational game promoting sustainable packaging disposal for EcoPHA's compostable coffee cups.

## About

CatCup Sorts teaches café customers how to properly dispose of PHA bioplastic cups through an engaging, gamified experience. The game supports EcoPHA's mission to make sustainable packaging adoption simple and frictionless.

## Features

- **Interactive Sorting Game** – Learn correct disposal methods for compostable cups
- **Educational Content** – Understand PHA bioplastics and home composting
- **Playable Experience** – Engaging gameplay designed for café displays
- **QR Integration** – Links to EcoPHA's sustainability system

## Why This Game?

Research shows cafés prioritize operational simplicity over sustainability messaging alone. CatCup Sorts reduces adoption barriers by educating customers in a fun, memorable way—making the entire EcoPHA system feel easy to use.

## Getting Started

```bash
git clone https://github.com/Manas-Pimple/cupcat-sorts.git
cd cupcat-sorts
npm install
npm start
```
